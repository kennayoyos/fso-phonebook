# 📞 fso-phonebook

This repository contains a simple Phonebook backend application built as part of **Full Stack Open – Part 3**.

It exists primarily to satisfy **Exercise 3.10 (deployment)**, where the application must be deployed to a public URL.

## 🚀 API Endpoints

- `GET /api/persons` – fetch all entries
- `GET /api/persons/:id` – fetch a single entry
- `POST /api/persons` – add a new entry
- `DELETE /api/persons/:id` – delete an entry
